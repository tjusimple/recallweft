# RecallWeft

A read-only memory retrieval client. It searches two sources in parallel, merges duplicate evidence, and keeps citations within a configurable UTF-8 byte budget.

Try the offline demo with Python 3.10+. No dependencies or credentials needed.

```sh
python recall.py --demo
```
