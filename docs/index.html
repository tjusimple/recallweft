Local persistent memory and retrieval

Two sources.
One evidence list.

Combine atomic memories and conversation history without losing where each result came from.

Try it locally

What’s different

Start a local store or connect your gateway.

Explicit scope
Both requests use the same team, user and agent identifiers. The client never writes to the upstream store.
Traceable evidence
Duplicate text is merged, and the output keeps its best citation from each source.
Bounded output
A UTF-8 byte budget limits retrieved text. A source error is reported explicitly, not treated as an empty result.

Persistent local service

Run it with Python 3.10+

Start the server, then write and query your own memories in another terminal. The data stays on disk across restarts. No cloud credentials or external service are needed.

git clone https://github.com/tjusimple/recallweft.git
cd recallweft
python serve.py start

# In a second terminal, from the same directory:
python serve.py remember "The release checklist requires a database snapshot."
python serve.py search "database snapshot"
