TencentDB-NEW / Independent project

Two sources.
One evidence list.

A read-only retrieval client for TencentDB Agent Memory. Combine atomic memories and conversation history without losing where each result came from.

Try it locally

What’s different

A retrieval layer, not a new memory engine.

Explicit scope
Both requests use the same team, user and agent identifiers. The client never writes to the upstream store.
Traceable evidence
Duplicate text is merged, and the output keeps its best citation from each source.
Bounded output
A UTF-8 byte budget limits retrieved text. A source error is reported explicitly, not treated as an empty result.

Offline demo

Run it with Python 3.10+

The demo uses synthetic records only. No gateway, API key or external service is needed.

git clone https://github.com/tjusimple/tencentdb-new.git
cd tencentdb-new
python recall.py --demo
